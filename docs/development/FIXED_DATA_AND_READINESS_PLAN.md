# 固定数据交付与实验就绪流程实施计划

> 本轮用户要求同时解决固定实验资料缺失与截图中的11项阻塞；使用已有课程自动评价范围，用户只需提供模型配置与密钥。实施采用独立子任务并行和集成验证。

**目标：** 新克隆自动取得可校验的固定主集与开发资料；准备正式实验时自动完成资料检查、模型文本/图像/并发能力检查和新快照冻结，保留真实错误、原始数据及历史结果。

**结构：** `app/datasets.py` 管版本化资源安装；`app/course_readiness.py` 管静态资格；`app/provider_checks.py` 管真实服务探测；`ApplicationService.prepare_experiment` 串接准备并返回可直接启动的预检。推理只读取冻结输入投影，评价金标不进入模型请求。

**约束：** 固定200题主集/分组与原始资产SHA不变；不清空旧调用账本、不伪造资格布尔、不静默换模型、不把不支持图像的模型当成E3可用。课程范围只统计调用次数；未知/可恢复错误仍保留记录、有界重试，鉴权和真实能力错误明确说明。

# 实验协议与实际范围

本页说明当前源码中的协议入口，以及报告实际运行的范围；完整冻结配置以对应运行的 `spec.json` / 导出包 `runtime/configuration.json` 为准。聚合成绩与限制见[主集结果](MAIN_RESULTS.md)，运行、资源与异常处理见[应用指南](../guides/APP_GUIDE.md)。

## 方法与固定配置

- 数据来自 TAT-DQA，保留 CC BY 4.0 归属。抽样与来源划分入口是 `configs/formal/source_protocol.json`；推理输入与评价金标分离。
- 检索器为 BM25 与固定 `all-MiniLM-L6-v2`。MiniLM revision、下载文件及校验身份见 `configs/formal/minilm-files.json`。
- 核心条件：E1 规则抽取；E2 文本生成；E3 同范围文本与图像生成；E4 文本与结构辅助生成。另保留旧规则比较器 E1_legacy。
- 正式配方见 `configs/formal/formal-v1.json`：k=2，随机种子20261023，生成条件重复3轮。正式模型与传输协议由 `formal_src/profile_lifecycle.py` 校验；更换服务模型不能静默视为同一实验。
- 输入按来源隔离，检索在同一文档候选证据中进行。文件、代码、提示和方案身份参与冻结与复核。

## 评价口径

主指标 `financial_uem_v1` 为自定义单位敏感精确评分，并报告 EM 与 token F1；不是官方 TAT-DQA 排行榜成绩。所有计划题保留在分母中，弃答/失败不排除；每题先平均重复轮次，再汇总问题。

四项主对比按财报来源簇 bootstrap 10000次，报告95%及四对比调整后的98.75%区间，不能把重复生成当独立问题。具体统计与主集局限以已保存结果为准，不凭最高点估计宣称稳定提升。

## 资源资格与复现

下载脚本生成候选材料，不会自动完成全部正式资格认定。课程自动模式使用官方金标自动评分并如实标注没有人工审核；它仍要求来源、输入、模型/服务兼容、预算及绑定资格证据。人工模式有额外审核要求。

精确复核需要原封存预测、任务、输入身份、资源登记和隔离评价文件。源码和结果表不能替代资源交付；没有 API 权限仍可做软件测试和具备材料时的封存结果复核。恢复旧任务需匹配其冻结版本，重跑新实验需记录新的版本与配置。

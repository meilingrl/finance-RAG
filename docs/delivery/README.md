# 课程交付

- `COURSE_SUBMISSION_MANIFEST.json`：课程导出白名单与必需文件。导出需要实际报告、AI使用声明、成员贡献声明及符合协议的封存评分结果。
- `COURSE_README.md`：导出包根 README 模板；其中操作路径按包根目录解释。

操作见[应用指南](../guides/APP_GUIDE.md)。源码包不包含原始数据、模型权重、完整运行工作区、密钥或 Git 历史。提供者须另行交付可访问的资源、身份清单和需要复核的封存工作区；只有哈希不能替代文件。

课程导出使用显式白名单，不要直接压缩整个本地工作目录。Git 仓库的当前文件与历史提交是不同范围；本次结构整理没有重写既有提交。报告、贡献、AI 使用、数据归属及实验限制均应如实保留。

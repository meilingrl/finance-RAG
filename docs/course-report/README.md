# 课程报告与个人贡献声明

- [项目报告](项目报告.md)：从课程主稿同步的最新正文、成员信息、实验分析与复现说明。
- [个人贡献声明表](个人贡献声明表.md)：从课程主稿同步的已填写内容；尚未填写的确认、证据和签名保持待办。
- `templates/`：原始课程模板。

课程目录中的主稿仍是后续修改依据；仓库版本同步正文并适配仓库内图片、模板及指南路径。本目录已按用户要求包含主稿中填写的成员与贡献信息，不再是省略身份信息的技术副本。发布到仓库不代表课程正式提交、全部待办完成或成员已经签字确认。

原始数据、逐题预测、运行日志和排版快照不随源码提供。正文引用的本地证据已注明交付边界；真实复现所需材料和权限见[应用指南](../guides/APP_GUIDE.md)。
